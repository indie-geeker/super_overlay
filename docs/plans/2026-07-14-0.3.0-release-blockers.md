### Task 1: Make Anchor Visibility Viewport-Aware

**Files:**

- Modify: `test/super_overlay_popup_anchor_tracking_test.dart`
- Modify: `lib/src/helper/overlay_manager_lifecycle.dart`
- Modify: `README.md`

**Step 1: Write failing partial-edge tests**

Add parameterized widget tests for top, right, bottom, and left clipping. Start
each 100x40 target fully inside the viewport, move it one logical pixel across
the selected edge, and assert that the target stays mounted, the popup remains
visible, and the rendered anchor rectangle follows the clipped target.

**Step 2: Run the partial-edge tests and verify RED**

Run:

```bash
flutter test test/super_overlay_popup_anchor_tracking_test.dart --plain-name 'popup stays open while its mounted anchor is partially outside the viewport'
```

Expected: FAIL on at least the top and left cases because negative global
coordinates currently close the popup.

**Step 3: Write failing fully-offscreen tests**

Add top, right, bottom, and left cases that move the same mounted target until
its rectangle has no positive-area intersection with the Overlay viewport.
Assert that `closed` settles, `isVisible` becomes false, and the registry no
longer contains the tag.

**Step 4: Run the fully-offscreen tests and verify RED**

Run:

```bash
flutter test test/super_overlay_popup_anchor_tracking_test.dart --plain-name 'popup fails closed when its mounted anchor leaves the viewport'
```

Expected: FAIL on at least the right and bottom cases because the current
geometry check does not reject those directions.

**Step 5: Implement the minimal runtime correction**

In the frame monitor, route attached popups directly through
`_anchorRectInOverlay`. Keep the current `_hasInvalidGeometry` path for
non-attached widget bindings. In `_anchorRectInOverlay`, return the transformed
rectangle only when it is finite, non-empty, and overlaps the Overlay-local
viewport with positive area.

Document that partial visibility remains tracked and complete viewport exit
fails closed.

**Step 6: Verify GREEN and regressions**

Run:

```bash

flutter analyze
flutter test test/super_overlay_popup_anchor_tracking_test.dart
flutter test test/super_overlay_popup_geometry_cases.dart test/super_overlay_widget_binding_cases.dart
```

Expected: all pass.

**Step 7: Commit**

```bash

git commit -m "fix: keep partially visible popup anchors active"
```
